# Klyvexa

Instagram DM automation and live inbox platform built on the official Meta Graph API.

## Features

- **Official Meta Graph API**: Webhook processing, 24-hour messaging window enforcement, and Human Agent tag support.
- **Safe Rate Limiting**: Conservative soft caps, recipient cooldowns, and spike protection.
- **Visual Flow Builder**: Multi-step comment-to-DM triggers and lead capture.
- **Live Inbox & AI Summary**: Real-time shared inbox with AI-generated conversation summaries.
- **Token Security**: AES-256-GCM encryption for stored credentials.

## Getting Started

```bash
# Install dependencies
npm install

# Run locally
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the dashboard.
